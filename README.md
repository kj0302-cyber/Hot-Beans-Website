# Hot-Beans-Website
A multi-page website developed as part of my Level 3 IT coursework, using HTML, CSS and JavaScript

This project was completed during the last academic year as part of my Level 3 IT coursework. It was my first experience developing a website using HTML, CSS and JavaScript.

I developed the website with guidance and support from my teacher, alongside Dev Dreamers' YouTube tutorials, which were used as learning resources throughout the process.

The project gave me the opportunity to apply these languages for the first time and develop my understanding of website structure, styling and basic interactivity.
